Privacy Policy

Liska Linux is developed with privacy in mind. The operating system does not include telemetry, analytics, or background services that collect personal information by default.


Package Downloads

When installing or updating software through LKPM, package requests are sent only to the repositories configured by the user. Repository operators may record standard server logs such as IP addresses, timestamps, and requested files according to their own privacy policies.


Third-Party Repositories

Users may configure additional repositories. Liska Linux Project is not responsible for the privacy practices, availability, or content provided by third-party repositories.


Local Data

Package databases, configuration files, logs, and caches are stored locally on the user's system. Liska Linux does not transmit this information unless explicitly configured by the user.


Open Source Transparency

Liska Linux is open source. Users are encouraged to inspect the source code, reproduce builds, and verify how the operating system behaves.

Contact
