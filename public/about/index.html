About

Liska Linux is a lightweight Linux distribution designed around one simple principle: "the system should obey its user, not the other way around".


Starting from a minimal command-line installation, every component is intentionally selected by the user. Nothing is installed unless explicitly requested, resulting in a predictable and transparent operating system.


User-Centric Package Management

At the heart of Liska Linux is the Liska Package Manager (LKPM). Unlike other package managers, LKPM does not automatically install dependencies. Instead, it reports required and optional packages, allowing users to decide exactly what belongs on their system.


This approach provides greater control over software, reduces unnecessary installations, and keeps systems tailored to individual workflows and hardware.


Flexible Repository Support

LKPM supports the official Liska repositories as well as compatible third-party package sources using the supported tar package format. Users are free to organize their own repositories while maintaining compatibility with the Liska ecosystem.


Minimal by Design

Liska Linux provides a clean command-line environment as its starting point. Rather than shipping a predefined desktop experience, it focuses on delivering a stable foundation that users can build upon according to their own preferences.


Built for Builders

Whether you're creating a workstation, development environment, server, or custom Linux distribution, Liska Linux provides a predictable base system that stays under your control from installation to daily use.
